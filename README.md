# ⛵ אפליקציית מועדון שייט (Sailing Club App & PWA)

אפליקציית מובייל-פירסט (PWA) ייעודית למועדוני שייט, המחליפה את קבוצות הוואטסאפ בניהול מסודר של הפלגות מועדון, הרשמות ותורי המתנה אוטומטיים, פיד קהילתי, גלריית תמונות, ופאנל ניהול חברים מלא.

---

## 🌟 יכולות עיקריות

1. **ניהול הפלגות, לוח שנה ומערכת קרדיטים**:
   - **לוח שנה חודשי אינטראקטיבי** המציג את כל מועדי ההפלגות, זמני יציאה וסטטוס.
   - **הפלגת מועדון (Club Sail):**
     - מינימום 3 משתתפים לסגירה ויציאה, מקסימום 6 משתתפים.
     - יורד בדיוק 1 קרדיט לכל משתתף שנרשם (מוחזר אוטומטית בעת ביטול).
     - חיווי ברור: "ממתין לחברים נוספים" לעומת "יציאה מובטחת".
   - **הפלגה פרטית (Private Sail):**
     - מינימום 3 שעות (עלות: 3 קרדיטים), ו-1 קרדיט נוסף לכל שעה נוספת (למשל 4 שעות = 4 קרדיטים).
     - מנוכה מחשבון החבר המזמין בעת הפתיחה.
   - **רשימת המתנה אוטומטית:** כשההפלגה מלאה, חברים נרשמים להמתנה (#1, #2...). בעת ביטול, הראשון עולה ומחויב בהתאם.

2. **ניהול צי כלי שייט ולוח דיווח תקלות**:
   - הגדרת שמות סירות, דגמים, קיבולת ומיקומי רציף.
   - סטטוס סירה חי: **זמין להפלגה** / **בהספנה ותיקון** / **לא זמין**.
   - דיווח תקלות ע״י חברים עם קטגוריות וחומרה (התקלה מוצגת בלוח מודעות פומבי לכלל החברים והמנהלים).

3. **משתמשים, אבטחה ואיפוס סיסמה**:
   - אימות והרשמה עם מייל וסיסמה מורכבת (לפחות 8 תווים, שילוב אותיות ומספרים).
   - מנגנון איפוס/שחזור סיסמה באמצעות קישור וקוד אימות במייל.
   - חברים חדשים נכנסים למצב **"ממתין לאישור" (Pending)** עד לאישור מנהל.
   - עדכון רמת הסמכה של משיטים (משיט 60, משיט 30, משיט 40, איש צוות וכו').
   - מחיקת משתמשים עם הגנה מפני מחיקת המנהל האחרון.
   - אפשרות איפוס מסד נתונים נקי לחלוטין (Clean Database).

3. **פיד קהילה ושיתוף**:
   - פרסום עדכונים וחוויות.
   - דחיסת תמונות אוטומטית במכשיר (Client-side) לפני ההעלאה לחיסכון בנפח וברוחב פס.
   - תצוגה מקדימה עשירה של קישורים (Open Graph).
   - נעיצת הודעות חשובות בראש הפיד ע״י מנהל, לייקים ותגובות.

4. **PWA והתראות Push**:
   - התקנה למסך הבית של כל סמארטפון (iOS Safari / Android Chrome) בלי חנויות אפליקציות.
   - תמיכה בהתראות Web Push על הפלגות חדשות, ביטולים, ועלייה מהמתנה.
   - פעילות במצב לא מקוון (Offline).

5. **פאנל ניהול (Admin Panel)**:
   - אישור או דחייה של חברים חדשים בלחיצה.
   - ניהול תפקידי חברים (קידום למנהל / הורדה לחבר).
   - הגדרות מועדון (שם, מקסימום משתתפים, חלון ביטול).
   - סטטיסטיקה ודירוג החברים הפעילים ביותר.

## 🚀 מדריך התקנה ופריסה (צעד-אחר-צעד למי שאינו מפתח)

### שלב 1: הקמת פרויקט ב-Supabase (בסיס נתונים ו-Auth)
1. היכנס ל-[supabase.com](https://supabase.com) והירשם בחינם.
2. לחץ על **New Project**, תן שם לפרויקט (למשל `sailing-club`) ובחר סיסמה לבסיס הנתונים.
3. בתפריט הצדדי ב-Supabase, לחץ על **SQL Editor** ואז על **New Query**.
4. פתח את הקובץ `schema.sql` מהפרויקט, העתק את כל תוכנו, הדבק ב-SQL Editor ולחץ על **Run**.
   * פעולה זו יוצרת את כל הטבלאות, מדיניות האבטחה (RLS), פונקציית הנעילה האטומית `join_sail_atomic` והטריגרים.
5. עבור ל-**Project Settings** -> **API** ושמור לעצמך את:
   - `Project URL`
   - `anon public key`

---

### שלב 2: פריסה לענן בלחיצה אחת ב-Vercel
1. העלה את קוד הפרויקט למאגר פרטי ב-GitHub (או Fork).
2. היכנס ל-[vercel.com](https://vercel.com) ולחץ על **Add New... -> Project**.
3. ייבא את המאגר מ-GitHub.
4. בהגדרות **Environment Variables** הוסף את המשתנים:
   - `VITE_SUPABASE_URL` = (ה-Project URL מ-Supabase)
   - `VITE_SUPABASE_ANON_KEY` = (ה-anon public key מ-Supabase)
5. לחץ על **Deploy**. תוך כדקה האפליקציה תהיה באוויר עם כתובת HTTPS מלאה!

---

### שלב 3: התקנה על הטלפון (PWA)
1. פתח את הקישור שקיבלת מ-Vercel בדפדפן בטלפון.
2. **באייפון (iOS Safari):** לחץ על כפתור השיתוף (מרובע עם חץ למעלה בתחתית המסך) -> בחר **"הוסף למסך הבית" (Add to Home Screen)**.
3. **באנדרואיד (Chrome):** לחץ על הבאנר הכחול העליון "התקן עכשיו", או דרך שלוש הנקודות בתפריט -> "התקן אפליקציה".
4. האפליקציה תיפתח כעת במסך מלא, כמו אפליקציה מחנות האפליקציות.
